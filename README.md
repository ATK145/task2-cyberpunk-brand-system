# Task 2: The Creative Visionary 🎨
**By Aisha Tariq Khan**

## Scenario
A tech startup is rebranding and needs high-quality visual assets for its website and social media. Stock photos are too generic. They need a unique "Cyberpunk-Corporate" aesthetic that is consistent across all images.

## Mission
- Generate high-fidelity, brand-consistent visual assets using Image Gen Models
- Develop a series of 5 images using Advanced Prompting (negative prompts, aspect ratios, lighting styles)
- Perform Image-to-Image translations to keep the same character consistent across different scenes

**Tools:** Midjourney · DALL-E 3 · Stable Diffusion
